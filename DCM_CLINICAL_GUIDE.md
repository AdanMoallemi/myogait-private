# DCM Clinical Gait Analysis Guide

Welcome to the MyoGait Clinical Pipeline! This guide will walk you through everything you need to know to get the environment set up, start the clinical dashboard, digitize a patient's case report form (CRF), and run a full markerless gait analysis.

---

## 1. Environment Setup (First-Time Only)

Before you can run the dashboard, you must set up your Python environment. We use **Conda** to manage dependencies securely.

1. **Open your Terminal** (or Anaconda Prompt on Windows).
2. **Navigate to the MyoGait directory**:
   ```bash
   cd /path/to/myogait
   ```
3. **Create the Conda environment**:
   ```bash
   conda create -n dcm-gait python=3.11
   ```
4. **Activate the environment**:
   ```bash
   conda activate dcm-gait
   ```
5. **Install the required packages**:
   ```bash
   pip install -e .
   pip install streamlit pandas
   ```
   *(Note: Depending on the specific pose models you want to use, you may need to install additional backends like `gaitkit`, `sapiens`, or `yolov8` as prompted by the system).*

---

## 2. Launching the Dashboard

Once your environment is set up, you can launch the graphical dashboard.

1. Ensure your conda environment is activated:
   ```bash
   conda activate dcm-gait
   ```
2. Start the Streamlit application:
   ```bash
   streamlit run dcm_dashboard.py
   ```
3. Your web browser should automatically open to `http://localhost:8501`. If it doesn't, click the link provided in your terminal.

---

## 3. The Clinical Database (CRF) Tab

The dashboard is split into two tabs. **You must always start in the Clinical Database tab.**

1. Click on **📂 Clinical Database (CRF)** at the top of the dashboard.
2. Select **`+ Create New Patient`** from the dropdown menu and type a unique ID (e.g., `DCM-001`).
3. Fill out the digitized Case Report Form. This includes:
   - Demographic Data (Height is especially critical for kinematics)
   - Surgical History
   - The modified Japanese Orthopaedic Association (mJOA) score
   - 10-Metre Walk Test (10MWT) results
   - Clinical Assessors (You can manage the list of assessors directly in Section 5)
   - Video File Log (Paste the paths to your raw GoPro videos here for safekeeping)
4. **IMPORTANT**: Click the **💾 Save Patient Profile** button at the very bottom of the page before switching tabs. If you do not save, your inputs will be lost!

---

## 4. Running the Gait Analysis Pipeline

Once the patient is created and saved, you can analyze their videos.

1. Switch to the **🏃 Pipeline Analysis** tab.
2. Under **Pipeline Setup**:
   - **Experimenter**: Select your name from the dropdown. (Use `+ Manage List` if you need to add yourself).
   - **Select Patient**: Choose the patient you just created (e.g., `DCM-001`).
   - **Recording Plane**: Specify if the video was taken from the side (`sagittal`) or the front/back (`coronal`).
   - **Pose Model**: Select the AI model you wish to use (e.g., `mediapipe`, `yolo`, `sapiens`).
   - **Visible Side**: For sagittal recordings, select which side of the body was closest to the camera (`left` or `right`). This prevents the occluded leg from generating noisy data.
3. Under **Video Selection**:
   - Provide the absolute path to your raw video file on your computer (e.g., `/Users/name/video.mp4`), or upload it directly.
4. Click **Run Clinical Analysis**.
   - The dashboard will display a spinner while it computes the biomechanics. This may take several minutes depending on the video length and the pose model selected.

---

## 5. Finding Your Results

Everything generated by the dashboard and the pipeline is safely stored in the `Output/` folder within your MyoGait directory.

All files are strictly organized by Patient ID and timestamp:
`Output/Patients/[Patient_ID]/[Timestamp]_[Video_Name]/`

Inside this specific folder, you will find:
- `README.md`: A permanent audit trail showing exactly who ran the pipeline, what settings were used, and any clinical flags.
- `run_metadata.json`: The machine-readable version of the pipeline settings.
- `profile.json`: A snapshot of the patient's CRF data.
- **Clinical Reports**: Beautifully formatted PDF and Excel files containing the full biomechanical breakdown (if you enabled them in the dashboard).
- **OpenSim Files**: `.mot` and `.trc` files for advanced musculoskeletal modeling.

You are now ready to begin processing your clinical cohort!
